# Portfolio website

My personal portfolio: a single `index.html` with no build step and no dependencies.

## Publish on GitHub Pages
1. Create a public repo named `<maazing6798>.github.io`.
2. Upload `index.html` (and this README) to the repo root.
3. Open **Settings → Pages**. Set the source to *Deploy from a branch*, branch `main`, folder `/ (root)`.
4. After about a minute the site is live at `https://<maazing6798>.github.io`.

## Personalise
Search `index.html` for these placeholders and replace them:
- `Your Name`
- `your.email@example.com`
- `your-profile` (LinkedIn)
- `maazing6798` (GitHub, used in 2 links)

When you publish a new case study, change its "Case study in progress" line to a link to its repo.
